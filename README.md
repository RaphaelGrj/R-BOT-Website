# R-BOT / Lumi — V1
Site HTML/CSS autonome.

Pour ajouter le rendu 3D : placer une image dans `assets/`, puis remplacer le bloc `.render` dans `index.html` par une balise `<img>`.

Pour ajouter une page : créer par exemple `robot.html`, puis ajouter un lien dans la navigation.

Les logos fournis sont déjà intégrés dans `assets/`.
